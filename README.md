## 安装与首次使用

仓库 yyxz223-stack/Living-Japan 只提供同一当前版本的三个用途入口：main 是唯一轻本体安装入口，source 是同版本协作源码，region-data 是当前地区资料。默认分支保持 main，普通安装不填分支。公共分支已清除旧程序、旧点库和旧提交历史，重复的 extension 分支已撤销；本机历史档案保留，公共仓库不再提供旧版本入口。

① 在酒馆扩展安装窗口填写 https://github.com/yyxz223-stack/Living-Japan.git，“分支或标签名”留空，选择“仅为我安装”，安装后刷新网页。旧 v3.6 用户先导出个人修改稿，保留并停用旧脚本，再打开扩展。

② 从达摩悬浮按钮、魔法棒菜单或扩展设置打开 Living Japan，首先下载首都圈。界面显示版本、大小、已下载量和进度；完成后进入工作区和导览。首都圈是必需资料，之后不能停用或移除。

③ 其他大区按需下载，下载后另行启用。停用保留已下载文件，更新保持原启用状态。北海道、东北、关东、中部、近畿、中国、四国、九州·冲绳仍按大区管理，不拆成行政区小包。

安装入口、个人备份和恢复步骤见 [安装与恢复](docs/安装与恢复.md)。

## 更新与个人保存

本体通过酒馆的 Git 扩展更新；地区资料通过扩展内资料管理下载、更新和启停。启动酒馆、刷新页面或完整重载扩展时自动检查一次；普通展开、收起和进入设置不会重复检查。下载由用户点击开始。

有更新时，地图入口显示 NEW，设置内显示提示与更新说明。版本和本次下载大小公开显示，内部校验值不出现在正常界面。未改变的内容块会复用；下载中断可以继续，完整保存并核验后才切换新版。

个人正文、修改稿、自建空位、资料挂接、收藏与设置保存在酒馆当前用户的 `living-japan-user-data.json`。地区安装记录另存为 `living-japan-region-packs.json`，资料块另存。公共资料更新不会覆盖个人文件；暂未启用地区对应的个人内容继续保留。

## 开发与发布

本目录是 source 源码协作分支。[源码协作与构建](docs/源码协作与构建.md)说明可直接执行的有限检查、完整构建所需外部冻结输入和未纳入范围；精确清单见 [发布文件清单](发布文件清单.md)，协作约定见 [CONTRIBUTING](CONTRIBUTING.md)。

源码协作、轻本体安装和静态地区下载是三份明确文件集合，不能把整个施工仓库作为安装包或上传集合。本轮分发由 `scripts/build-region-distribution.py` 从明确的新运行输入导出 `framework/` 和 `region-packs/`，本体已配置 region-data 的公网目录地址；后续发行仍从冻结输入另建候选。

原始来源、第三方素材和相应许可随对应交付保留。源码许可证仍待项目所有者选定，现有图标或数据许可证不代表项目源码许可。公开上传、定期同步、协作者邀请和远端设置仍须在具体范围确定后确认。

发生问题时，提供“检查”页诊断、资料包页面的错误文字和最后一步操作。不要公开个人存档、聊天内容、令牌或本机路径。
