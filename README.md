## 酒馆安装

① 在酒馆“扩展 → 安装扩展”中粘贴 `https://github.com/yyxz223-stack/Living-Japan.git`。**分支留空即可**，默认安装最新 main；也可明确填写 main。`main` 是唯一安装入口；不再提供 `extension` 重复安装分支。

② 旧版用户先导出个人备份，保留并停用旧脚本。安装完成后刷新酒馆网页，从达摩按钮打开 Living Japan，下载约 51 MB 的首都圈资料。等“下载与校验完成”后点击“开始使用”。无需解压或重启电脑。

③ 首都圈为必需资料并常驻；其他大区按需下载，下载后再单独启用。错误处理与恢复方式见[安装与恢复](docs/安装与恢复.md)。

当前冻结六批22区34,693对象；新地点正文留空，其他大区主要提供底图与公共资料，新铁路站网另开。旧程序和旧点库已从当前 main 文件树移除，公共分支以当前净版本重新建立，不再提供旧版历史入口；本机档案不变。
