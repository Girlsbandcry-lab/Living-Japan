# Living Japan

用于小说写作的 SillyTavern 扩展。它根据聊天中的地点、时间和天气挑选离线背景资料，通过 `{{livingjapan}}` 宏交给写作模型。提供横版、竖版和手机布局，以及个人地点、正文和词条编辑。

本体 **v20261103.2** · 首都圈资料 **SDQ20261102.1**

## 安装

① 在酒馆的“扩展 → 安装扩展”中粘贴仓库地址，分支或标签留空。安装或更新完成后刷新酒馆网页。[Living Japan 仓库](https://github.com/Girlsbandcry-lab/Living-Japan.git)

② 首次安装或更新到本版后，会自动打开完整流程演示。用“上一步／下一步”查看，点“结束本章”回到酒馆。演示使用独立示例，不改你的聊天、地点和草稿。

③ 从达摩按钮、魔法棒菜单或扩展设置打开 Living Japan。首次下载约 67 MB 的首都圈资料，校验后点击“开始使用”；已装同版本资料可继续使用。其他大区按需下载。详见 [安装与恢复](docs/安装与恢复.md)。

## 本次程序更新

- **快捷切换描写详略。** 电脑右键或手机长按达摩，可直接选择背景／简写／标准／细写。即时保存，并与读取设置同步；其它未保存的填写内容保留。四类资料开关使用当前名称。
- **完整操作演示。** 十章80步自动打开页面，演示填写、保存、查看结果及返回，并解释页面之间的关系。金色高亮和轻微呼吸光晕标出当前讲解位置。章内可前后查看，误点或按Escape不会退出，只能结束整章；章末可接着看下一章。
- **新旧说明分别保留。** 首次进入新版流程不受旧版“不再提示”影响，同版重开不反复弹出。从“设置→备份与说明”可以重看完整流程，也可单独打开原来的页面讲解查按钮用途。

## 既有功能

- **地点与出行。** 具名地点按登记的行政区和有效名称配对。同名行政区可借城市或都道府县区分。普通追加名称和交通两端使用行政路径及有效完整名。自建地点保存新坐标后，已有路线会刷新，保留所选出行方式。
- **附加资料。** 地点编辑可按分类或搜索选词条，查看路径、已挂状态和正文，并可前往资料页编辑后返回地点草稿。同级介绍的数量与未细分说明分别就近显示，具体类型可设为 0。
- **条件与正文。** 支持按旬取用、真正不限地域的正文、词条独立有效词，以及三小时时段快捷填写。15 项内置活动的本级正文使用可编辑的默认日期范围，在这些活动下新建适用情况时也会预填对应范围。个人显式设置优先，取用仍需有效入口并满足适用条件。
- **诊断与备份。** 结果摘要按选中记录显示日期、时刻、天气、地点及来源。个人备份可导出为 JSON。导入先预览，再合并正文、个人地点、词条与设置。地区包模式下，可用的正文槽按当前地区与合并后的个人资料识别。
