# Living Japan

用于小说写作的 SillyTavern 扩展，提供地点地图、写作资料浏览和个人内容保存，支持横版、竖版、手机布局及 `{{livingjapan}}` 宏。

本体版本：**v20261102.3** · 首都圈资料：**SDQ20261102.1**。

## 安装与首次使用

① 在酒馆“扩展 → 安装扩展”中粘贴仓库地址：https://github.com/Girlsbandcry-lab/Living-Japan.git 。分支或标签名留空，安装完成后刷新酒馆网页。

② 从达摩悬浮按钮、魔法棒菜单或扩展设置打开 Living Japan，下载约 67 MB 的首都圈资料。等待“下载与校验完成”后点击“开始使用”。首都圈是必需资料，之后不能停用或移除。

③ 其他大区按需下载，下载后再单独启用。停用会保留下载文件，更新也会保留此前的启用状态。无需下载 ZIP、解压或重启电脑。

详细步骤、个人备份与出错处理见 [安装与恢复](docs/安装与恢复.md)。

## 本次程序更新

- 同级相关地点中，有内部或下属地点的对象优先显示；地图与地区页使用一致规则，地区目录保留收藏优先。
- 电脑窗口不再随聊天输入框增高而缩小；横版、竖版顶部增加拖动握柄，使用窗框内侧边缘缩放，取消外露箭头。
- 横版全地图的“返回”按钮保持单行，回到普通地图后隐藏。
- 手机自动采用手机布局，填满浏览器并露出聊天输入框约 1～2 行；键盘弹出时保持窗口尺寸、整体上移，收起后复位。
- 地点可新增、编辑资料和地图选点；恢复内置先进入草稿，保存后生效。已有输入取消时会确认。
- 收藏地点在同级展开宏内优先显示；隐藏地点仍可编辑，但不显示自身的宏文字和地图点位，其他链路照常。
- 每个具体类型独立设置同级地点数量，默认 5 个，可设为 0；每次生成回复重新抽取，同一次宏与诊断一致。
- 三种布局统一常用操作，完整新人导览分为 7 篇、44 步；入口在“设置 → 备份与说明”。

## 当前资料范围

首都圈包含 32 个已接收来源行政区、**62,575 个对象**，其中有 61,151 个 Overture 源地点和 1,424 个结构对象，尚未覆盖首都圈全部行政区。新地点正文暂留空，可用于个人补写。

其他大区目前主要提供底图与公共资料，具体覆盖以资料页说明为准。新铁路计算站网尚未接入。

## 更新与个人保存

本体通过酒馆扩展管理更新；地区资料通过 Living Japan 内的资料页下载、更新和启停。启动酒馆、刷新网页或完整重载扩展时会自动检查更新，设置中也可手动检查。地图入口的 NEW 和设置中的提示会说明可用更新，下载由用户点击开始。

未改变的资料会复用，下载中断后可继续。公共资料更新不会覆盖个人正文、修改稿、自建空位、资料挂接、收藏和设置；停用地区也会保留对应个人内容。更新或导入备份前，建议从“设置 → 备份与说明”导出个人备份。
