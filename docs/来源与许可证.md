# 来源与许可证归属

源码许可证尚待项目所有者选定，本次发布没有代选或新增根级 LICENSE。公开可见不等于已提供任意复用授权。

assets/map-icons/sources.json 保存所用图标的原始来源 URL、SHA-256 与转换说明；Lucide、Tabler、Maki、Material Design 图标的原有许可证文件随同目录保留，Apache-2.0 全文也保留。以上许可各自覆盖对应第三方素材，不能当作整个 Living Japan 程序的源码许可。

本轮地点依据 Overture 2026-10-21.0 已审回货，首都圈冻结范围为 32 个来源区、62,575 对象。地点、底图、道路和图层的实际来源及许可随 region-data 中对应公共资料交付；本源码树不复制原始点库，不另作来源法律判定。

旧点位、正文或铁路资料即使曾在施工仓库中出现，也不因此进入本次公开发布。素材、数据和程序的许可分别管理。
