# 源码协作与构建边界

**地点编辑入口已迁至 [https://github.com/yyxz223-stack/Living-Japan-Places](https://github.com/yyxz223-stack/Living-Japan-Places)。本仓库只由所有者维护本体代码，不向地点协作者授予写权限。随版行政区合同只作阅读参考，不在本仓库另建地点正本。**

本目录是 source 分支的明确源码集合，不是整个施工仓库。main 是唯一默认轻本体安装入口，普通安装留空分支；region-data 是同版本当前地区资料。重复 extension 分支撤销，三个公共分支均以当前净树重建公开起点，旧程序、旧点库及旧提交历史不作为公共协作入口。本机历史档案保留，协作者以本分支当前版本重新取得工程。项目状态入口是 PROJECT_TODO.md。

## 已包含

- 本轮发布清单中列明的当前 JavaScript、CSS、HTML、图标及原许可；不含内嵌旧站名文件和旧交通 JSON。
- 轻量全国导航、空运行基础、空下载源配置。它们供开发接线，source 不作为用户安装分支。
- 地区分发器、稳定分块回归、下载管理／面板／本体更新／启动时机的自足测试，及测试需要的 DOM 替身。
- 明确的行政区共享流程、模板、分类合同和资料合同。它们用于协作阅读，不把动态调度或某批任务视为新授权。

## 可直接运行的有限检查

需要本机已有兼容的 Node.js 和 Python；不自动安装环境。package.json 的 test 仅运行本目录列出的五个 Node 测试文件，test:distribution 运行自造输入的四项分发器回归。它们不读取旧地点库、个人保存或中央在跑资料。

原施工仓库的其余测试未整体复制。其中 region-pack-runtime.test.mjs 含直接依赖旧根运行库的历史用例，material-pipeline.test.mjs 依赖旧 data/base.json，当前精简源树没有该输入，不能把未纳入的整套检查声称为可直接通过。后续迁移这些测试时应另列范围，不以补回旧数据来满足它们。

## 完整发布构建的外部输入

分发器入口为 scripts/build-region-distribution.py。维护者须另行提供已审收、已冻结的新运行目录，显式指定 runtime-root；本轮对应 overture-test-3a3540090b7aef00、22 区、34,693 对象。输入包括新 national manifest、运行基础、完整新地点与各索引，以及批准的清洗底图、道路、图层和来源许可。可复用资源若未在运行目录中，应按分发器明确清单提供；不得回退到旧地点、正文、站名或铁路网。

本源码树不含这些完整构建输入，也不声称单独克隆就能重新生成全部地区资料。分发器输出和 SHA 校验由明确输入复现；中央区档、原始 Overture 与离线工作库由维护者按任务另行交付，不公开复制。

行政区全量工程执行工具、区输入和领取状态不在本次程序协作子集中。参与资料施工时，维护者按冻结版本另交完整工具与批准区包；共享规则中的工具路径是该完整交付的相对路径，不能把此精简树冒充可直接派区的工程总包。

## 预览

scripts/serve-package-preview.mjs 读取已生成分发目录。使用 LJ_DISTRIBUTION_ROOT 指向独立候选，LJ_PREVIEW_USER_ROOT 指向独立预览保存目录；不配置时的历史默认目录不属于本源码交付。预览服务器会把资料读取指向所选本地 region-packs，仅用于隔离浏览器操作，不能验证 raw GitHub 下载。

本体和地区下载保留既有真实酒馆独立验收；此前通过的新独立酒馆公网 Git 安装、首都圈下载和程序更新，限定为明确指定 extension 分支；默认 main 入口当时漏验，本轮已修正，并通过分支留空的真实安装、达摩入口与新版地图布局验收。本轮使用已有同版地区文件，不重复计作首次公网下载。此源码树的独立测试只证明公开子集自身可检查；日常用户、目标模型与物理设备仍待实测，详见验证说明.md。源文件清单与 SHA 见 source-files.json；该清单不自列。源码许可尚待所有者选定。
