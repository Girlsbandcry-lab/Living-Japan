# 源码协作与构建边界

地点编辑入口是[Living-Japan-Places](https://github.com/Girlsbandcry-lab/Living-Japan-Places)。本仓库 source 分支提供本体维护源码，不另建地点正本。main 是普通用户默认安装入口，region-data 是唯一当前公共资料目录。

## 当前内容

本体 **v20261102.2**，适配首都圈 **SDQ20261102.1**。源码包括当前JavaScript、CSS、HTML、图标及原许可、轻量全国导航、空运行基础和地区下载配置；不内嵌旧点库、旧正文或旧站名文件。source 中的共享行政区合同只作阅读参考，不自动接管在建区或中央调度。

## 可独立运行的有限检查

本机已有兼容Node.js和Python时，package.json 的 test 运行本分支列出的 **16 个Node测试文件**，test:distribution 运行分发器自造输入检查。包含下载管理、启动更新、诊断显示，以及新增地点草稿、地图选点、收藏、三布局导航、设置、资料搜索输入和完整导览。

这些测试不读取旧根地点库、个人存档或内部目录。施工仓库中依赖 data/base.json、完整旧地图或旧交通资料的测试没有复制进来；不为满足旧用例把已退出的旧资料带回公开源码。源码有限检查不替代浏览器、真实SillyTavern、模型或实体设备验收。

## 完整发布构建的输入

scripts/build-region-distribution.py 需要维护者显式提供已审收、冻结且适合公开的 runtime-root。本版继续采用32个来源区、62,575对象的既有公开输入，按同一清单与内容指纹使用地区资料。输入含national manifest、运行基础、新地点及索引，以及批准的底图、道路、图层、来源和许可；不回退到旧地点或旧正文。

完整构建输入不在 source 中，单独克隆本分支不能重建全部地区资料。程序本体与地区版本可分别更新；只更新程序时不重复制一份地区库。source-files.json 记录本分支文件及SHA，不自列。

## 预览与发布

scripts/serve-package-preview.mjs 读取已生成分发目录。LJ_DISTRIBUTION_ROOT 指向独立候选，LJ_PREVIEW_USER_ROOT 指向独立保存目录。默认历史目录不是公开交付输入。本地资料预览不能代替公网下载测试。

本版验证层级见[验证说明](验证说明.md)。main 保持无分支名安装入口，region-data 当前树只留最新清单引用块；普通Git提交历史不作为用户选择旧版本的安装入口。源码许可仍待所有者选定。
