本页对应本体 **v20261102**、首都圈 **SDQ20261102**。已获所有者确认发布；默认 main 已改为最新轻本体，旧版已从当前发布树移除。此前 extension 分支已完成真实酒馆 Git 安装及首都圈公网下载；默认 main 的新增验收见验证说明。当前状态见 [项目待办事项树](https://github.com/yyxz223-stack/Living-Japan/blob/main/PROJECT_TODO.md)。

## 首次安装

① 旧 v3.6 用户先导出个人修改稿，保留原脚本。在酒馆“扩展 → 安装扩展”中粘贴 `https://github.com/yyxz223-stack/Living-Japan.git`，“分支或标签名”留空即可，默认安装最新 `main`；也可明确填写 `main`。不要把 GitHub 的 `/tree/…` 页面地址填作安装地址。`main` 是唯一安装分支；`source` 用于同版本协作，`region-data` 用于当前资料下载。

② 安装完成后刷新酒馆网页，停用旧 Living Japan 脚本，从达摩悬浮按钮、魔法棒菜单或扩展设置打开本体。首次先下载首都圈，等待下载、保存、核验和载入完成，再进入工作区和导览。首都圈为必需资料，不能停用或移除。

③ 需要其他大区时，在地区资料页下载，再单独点击启用。停用只停止载入，保留下载文件；更新保留此前的启用状态。有旧稿时，从“设置 → 备份与说明”先预览导入统计，再确认应用；宏继续使用 `{{livingjapan}}`。

通过酒馆仓库安装时无需下载 ZIP、无需解压、无需安装 Python，也无需重启电脑。若使用另行提供的 ZIP，本体可以使用，但 ZIP 安装不带 Git 信息，不能把它当作已验证的 Git 自动更新安装；具体路径和恢复说明以该候选交付页为准。

## 保存与更新

个人正文、设置、空位和偏好保存在酒馆当前用户文件区的 `living-japan-user-data.json`。地区状态使用独立的 `living-japan-region-packs.json`，内容块以 `living-japan-pack-` 开头。不要把这些个人运行文件移入扩展目录或上传公共仓库。

本体更新完成后刷新网页。地区下载与更新完成后由扩展载入，不需要重启电脑。启动、刷新或完整重载扩展会自动检查一次；设置保留手动检查。NEW 和设置提示说明有更新，下载仍由用户操作。

下载中断可重新开始并继续复用已经确认的内容块。新版完整保存、核验后才替换旧版。公共资料更新和其他大区停用不会覆盖个人稿、收藏、开关及挂接。个人稿保存失败时保留编辑框，先复制未保存文字；以“已保存并读回”为成功依据。

## 恢复与出错信息

① 更新前通过“设置 → 备份与说明”导出个人备份，并保留原安装版本。导入备份前先看新增、覆盖和无法对应内容的统计，不按名称猜配旧稿。

② 需要回退旧脚本时，先导出新扩展的完整个人备份，再停用新扩展、启用原 v3.6。旧脚本不能承接所有新建槽，保留新扩展备份及地区文件供以后恢复。

③ 页面可打开时，提供“检查”页诊断以及最后一步操作；下载错误另附地区名称、进度阶段和错误文字。无法启动时，提供酒馆窗口中带 `[Living Japan]` 的错误及浏览器报错。日志先去除聊天内容、令牌和本机路径；个人文件只在确需排查时另行约定交付。
