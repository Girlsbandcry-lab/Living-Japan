# 安装、更新与恢复

本页对应本体 **v20261102.2**、首都圈资料 **SDQ20261102.1**。

## 首次安装

① 在酒馆“扩展 → 安装扩展”中粘贴仓库地址：https://github.com/Girlsbandcry-lab/Living-Japan.git 。分支或标签名留空，安装完成后刷新酒馆网页。

② 从达摩悬浮按钮、魔法棒菜单或扩展设置打开 Living Japan。首次先下载约 67 MB 的首都圈资料，等待“下载与校验完成”后点击“开始使用”。首都圈是必需资料，之后不能停用或移除。

③ 需要其他大区时，在资料页下载，再单独点击启用。停用只停止载入，保留下载文件；更新会保留此前的启用状态。正文宏使用 `{{livingjapan}}`。

按上述方式安装无需下载 ZIP、解压或重启电脑。

## 当前能用的资料

首都圈包含 32 个已接收来源行政区、62,575 个对象，尚未覆盖首都圈全部行政区。新地点正文暂留空，可用于个人补写；旧正文不会随地点资料下载自动恢复。

其他大区目前主要提供底图与公共资料，各包覆盖范围以资料页说明为准。新铁路计算站网尚未接入。

## 新增、编辑与取消

在地区页点“新增”建立个人地点，也可选中地点后点“编辑地点资料”，修改名称、一句话、正文、类型及资料词条，并在地图选点。恢复内置会先放入草稿，检查后保存；尚未保存的更改取消时会先确认。资料分类、地域和片段的新增窗口也会保留未确认放弃的输入。

收藏会在同级展开宏内优先显示。隐藏不从界面删除地点，只隐藏自身宏文字和地图点位，其他链路保留。各具体类型的同级展开数量在地点设置中分别调整，默认 5 个，可设为 0。

“设置 → 备份与说明”提供 7 篇、44 步完整引导，按当前横版、竖版或手机布局显示实际入口；可随时退出或分篇查看。

## 保存与更新

本体通过酒馆扩展管理更新，更新完成后刷新网页。地区资料在 Living Japan 内下载和更新，完成后自动载入，无需重启电脑。启动酒馆、刷新网页或完整重载扩展时会自动检查更新，设置中也可手动检查。地图入口的 NEW 和设置中的提示会说明可用更新，下载由用户点击开始。

未改变的资料会复用，下载中断后可以重新开始，继续使用已保存的完整内容。新版下载、保存和校验完成后才会替换旧版。公共资料更新和地区停用不会覆盖个人稿、收藏、开关及挂接。

个人正文和设置保存在酒馆当前用户的 `living-japan-user-data.json` 中，地区安装记录为 `living-japan-region-packs.json`。这些文件由扩展管理，不需要搬到扩展安装目录。

个人稿保存失败时，先复制编辑框中尚未保存的文字；以“已保存并读回”为保存成功的依据。

## 备份与恢复

① 更新或导入前，从“设置 → 备份与说明”导出个人备份。使用旧 v3.6 脚本的用户，先导出个人修改稿并保留原脚本，再停用旧脚本、使用新扩展。

② 导入备份时，先预览新增、覆盖和无法对应内容的统计，再确认应用。不要仅凭相同名称把旧稿配给不同地点。

③ 如需回到保留的旧脚本，先导出新扩展的完整个人备份，再停用新扩展、启用原脚本。旧脚本不能承接所有新增个人内容，保留新扩展备份和地区文件，供以后恢复。

## 出错时提供什么

页面可以打开时，请提供“检查”页诊断和最后一步操作；下载出错时，另附地区名称、进度阶段及错误文字。无法启动时，请提供酒馆窗口中带 `[Living Japan]` 的错误记录和浏览器报错。

分享日志前去除聊天内容、令牌和本机路径。个人存档只在确需排查时另行约定提供。
