# 安装、更新与恢复

适用本体 **v20261103.2**、首都圈资料 **SDQ20261102.1**。

## 首次安装或更新

① 在酒馆“扩展 → 安装扩展”粘贴仓库地址，分支或标签名留空。已有安装可从酒馆扩展管理更新。完成后刷新酒馆网页。[Living Japan 仓库](https://github.com/Girlsbandcry-lab/Living-Japan.git)

② 首次安装或更新到本版会自动打开完整流程演示，可整章退出。同版重开不再自动弹出。然后从达摩按钮、魔法棒菜单或扩展设置打开 Living Japan；首次下载并校验首都圈资料后点“开始使用”。其他大区按需下载。无需下载 ZIP、解压或重启电脑。

③ 写作提示词可使用 `{{livingjapan}}` 宏。聊天中写出行政区和地点的有效名称。同名行政区再补城市或都道府县。地图的“追加名称”和“出发”可直接带出行政路径。

## 地点、词条与导览

地区页可新增地点或编辑已有地点。地点编辑中的“附加资料”可按类查找、搜索、查看正文和管理挂接。公共词条在资料页编辑。地点设置中的同级介绍按具体类型控制，设为 0 时该类型不列同级参照。

在“设置 → 备份与说明”可从头重看完整流程，也可选择一章。演示会自动打开真实页面、填写示例、保存并展示结果；章内用上一步／下一步查看，点“结束本章”回到原工作。示例保存只留在演示中，原页面和未保存草稿保留。系统文件选择、更新和宏接入以明确标注的操作示意讲解。

忘记某个按钮用途时，使用同页的“页面讲解”。电脑右键或手机长按达摩可打开快捷窗，立即切换背景／简写／标准／细写；它与读取设置控制同一项。

## 个人备份

① 在“设置 → 备份与说明”点击“导出用户备份”。浏览器没有直接下载时，可点击页面出现的“保存备份文件”链接保存 JSON。备份包含已保存的正文、未对应的修改稿、自建空位、地点改动、词条及挂接、开关和个人偏好。尚未保存的编辑草稿需先保存，再重新导出。

② 恢复时从同一页选择备份 JSON，先查看新增、覆盖和未对应统计，再确认。未启用地区的正文可能暂时无法对应，备份会保留这些内容。导入完成后，以“已导入并读回确认”为准。布局和窗口位置等偏好刷新网页后生效。

③ 地区安装记录和内容块由地区资料管理，聊天由酒馆另行管理。将备份恢复到另一环境时，按需安装相同地区。旧脚本用户应先保留原脚本及其备份。

## 出错时提供什么

请提供本体与地区版本、最后一步操作和页面上的错误原文。导入问题请附预览统计或失败提示，地区下载问题请附地区名称和进度。若提示其他页面已保存新内容，先复制尚未保存的文字，再刷新后重试。分享日志前去掉聊天内容、凭证和个人路径。
