# 验证范围

本体 **v20261103.1**，首都圈资料 **SDQ20261102.1**。本版更新程序，沿用已收录的 32 个来源行政区和 62,575 个地点对象。

## 检查内容

- **资料条件。** 检查按旬、时刻与天气，通用资料与独立有效词，以及 15 项内置活动的默认日期范围。保存个人显式条件时，沿用原有优先关系。
- **地点与出行。** 检查行政区与有效地名配对、交通两端带行政路径、地点改坐标后的路线刷新，以及地点附加资料的保存与返回。
- **个人备份。** 检查完整个人备份与较小备份的合并、可用和未启用地区的正文槽、同一记录覆盖，以及无冲突的目标内容保留。导入界面分别列出正文和个人资料的变化。
- **界面说明。** 检查诊断摘要、三小时时段填写、同级额度说明及分篇导览。

## 独立酒馆验证

- 通过真实备份界面生成 472,984 字节的 JSON，取出后写入磁盘，文件与界面生成的原字节 SHA-256 一致。用这份文件在独立酒馆的正式导入界面预览、取消，再重新选择并确认导入。取消前后个人数据一致。
- 确认导入后，正文新增 38、覆盖 1，另有 1 条刻意构造的未对应稿被保留。自建正文空位新增 7，资料登记新增 38、覆盖 1，已有地点的个人修改新增 3 条，自建地点新增 9 个。保存后读回逐字段比对，与预期无差异。
- 刷新酒馆并重开扩展后，界面读回 3 处地点修改、9 个自建地点、11 个分类、1 个地域、26 个片段、1 处地点资料和 1 项挂接。实际打开核对了自建地点正文、保存的地图坐标及处于暂停状态的附加词条。未对应稿仍为同一条。
- 这次已核对界面生成的备份字节及真实导入。受控浏览器对常规下载的结果未能确认，普通 HTTP 小文件也出现同样情况，因此没有记录下载管理器验收结论。
- 行政配对样例的 Main Prompt 宏正文为 571 字，与扩展预览一致。交通参考实际追加到聊天输入，并检查了随后的宏组装。

- 在独立酒馆竖版面板连续阅读十篇导览的 90 步。实际走过地点新建、编辑、附加资料选择、有效词和条件表单，并验证导览操作保留未保存草稿。另检查了 1280×960 横版与 390×844 窄屏布局。

## 证据边界

代码检查、独立酒馆操作、Main Prompt 的实际宏组装各自记录。宏展开可以核对进入提示词的资料，目标模型生成和采用资料的效果仍待观察。实体手机与日常酒馆的表现留待实际使用确认。
